# 운영 소스 이관 체크리스트

목표: Cloudflare에서 실제 동작 중인 흙별 운영본과 일치하거나 차이가 명시된 **재현 가능한 GitHub 기준 소스** 확보.

## 대상과 출처

- [ ] Cloudflare `sandstar`의 최신 배포 버전 ID와 immutable source/asset 구성을 읽기 전용으로 확보.
- [ ] Cloudflare `sandstar-title-bridge` 별도 스크립트·라우트·버전 및 원본을 확인.
- [ ] 공식 Drive QA/게임 HTML 파일과 사용한 에셋 목록 및 SHA-256 추출.
- [ ] 기존 개발 통합본 `v19`, 광부·로프·보물상자·드릴·농사 M3·BGM·NPC 대사·타이틀의 차이를 체크리스트로 매핑.
- [ ] 비밀정보 및 외부 에셋의 라이선스/재배포 권한 확인. 대용량 바이너리와 중복 임베디드 데이터를 무심코 Git에 커밋하지 않음.

## 수용 게이트

- [ ] 기준 게임을 재현할 수 있는 소스/구성/필수 에셋이 추적 가능함.
- [ ] HTML/JS와 운영 Worker 버전/아티팩트 간 동일성 또는 알려진 차이를 해시와 diff로 기록.
- [ ] PC와 Android Chrome에서 핵심 조작, 5개 월드 전환, BGM, 메뉴, 저장·불러오기 회귀 검증.
- [ ] OG·SEO·robots·healthz 및 타이틀 브리지 경로 확인.
- [ ] 사용자 세이브 파괴·마이그레이션 부작용이 없도록 검증하고 명시적 복구 경로 확보.
- [ ] 검토된 PR을 병합하고 GitHub 정본 승격 여부를 별도로 판단. **운영 배포와는 별도 의사결정.**

이 문서는 절차만 명세하며 위 항목의 완료를 의미하지 않음.
