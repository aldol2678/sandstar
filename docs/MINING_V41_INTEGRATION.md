# 흙별 광산 확장 통합 준비

광산 확장 P1.6-F 보존본은 [Draft PR #9](https://github.com/aldol2678/sandstar/pull/9)에 있다. 조각 11개를 복원해 2,490,263바이트와 SHA-256 `444edeeaf6978b3aa575a092d64aae314743bb50e8eb3bef6d550dab38589ada`를 확인했다. #9 문서의 v31은 당시 기준이다.

Cloudflare에서 2026-11-23 KST 기준 Worker v41 `8b55cd67-1c76-4d75-ab1e-40ee437727d3`의 운영 트래픽 100%를 확인했다. [PR #13](https://github.com/aldol2678/sandstar/pull/13)의 v41 아카이브에서 추출한 게임 스크립트가 운영 홈페이지의 게임 스크립트와 바이트 단위로 일치했다. 페이지 전체는 라우트에서 주입하는 타이틀 코드와 태그 등으로 차이가 있다.

| 범위 | 통합 결과와 남은 검증 |
| --- | --- |
| 곡괭이 결 읽기 | 첫 후보에 구현. 자연 광석을 캐면 8초간 같은 광석을 추적한다. 연속 최대 3단계이며 기존 +7·+15·+20 강화에 따라 단계당 5~8%의 채굴 효율이 적용된다. v41의 기본 월드 생성 v2부터 활성화된다. 곡괭이 이외의 도구, 설치한 블록, 보호 구간에는 적용되지 않는다. |
| 드릴 | v41의 기본 드릴을 기준으로 모터·비트·발열·연속 천공을 옮길 범위를 별도로 검토한다. 채굴 거리·시설 보호·화물 상한·기존 강화 효과를 함께 검증한다. |
| 해머 | v41의 인접 4방향 범위 피해와 후보의 코어·균열 효과가 겹친다. 기본 범위 피해와 대체 관계를 정한 뒤 보호 블록, 중복 보상, 저장 복원을 확인한다. |
| 로프 | v41의 한 번 탭 자동 상승과 P1.6-F의 탭 연결·해제, 수동 조작, 선택 자동 상승은 입력 규칙이 다르다. 기본 조작을 정의하고 연쇄·스윙·지표 탈출·긴급 구조를 PC 및 Android에서 검증한다. |
| 광산 지형·보상 | v41의 첫 채굴 X46, 시작 발판 보호 18칸, 기존 보물·작업대·대장간을 기준으로 대조한다. 동굴 및 보상 장부의 이전은 월드 생성 버전과 기존 채굴 편집을 검증한 뒤 판단한다. |
| 농장·요리 | 운영 v41과 농장·요리 #13 후보를 각각 빌드 입력으로 검증한다. #13을 먼저 병합할 필요는 없고, 실제 출시 기준선이 바뀌면 새 기준선을 다시 확인한다. |

## 재현

[PR #13 커밋 `32c2904`](https://github.com/aldol2678/sandstar/tree/32c2904b7688df1805f0ebebdc57b601e631eb16)의 `release/v41/main.mjs` 또는 해당 커밋의 기본 `tools/farm-cooking-b/build.sh` 출력 `fcb-main.mjs`를 입력으로 쓴다. 출력 파일은 새 경로를 지정한다.

```sh
node tools/mining-pickaxe-trace/build.mjs "$baseline_worker" "$candidate_worker"
node --check "$candidate_worker"
SANDSTAR_BASE_WORKER="$baseline_worker" SANDSTAR_TRACE_WORKER="$candidate_worker" \
  node --test tools/mining-pickaxe-trace/qa.mjs
```

| 빌드 | 입력 Worker SHA-256 | 후보 Worker SHA-256 |
| --- | --- | --- |
| 운영 v41 | `7da5888cd96d8b99b624e06d59a5492b29b3b67b442bc421f5e72ebc6a4ba5c3` | `2fbe97fab63dae3082b4b40bbc71701c3a993da43e00b2d7e59768bb34a38390` |
| v41 + 농장·요리 #13 | `3b36af90b2bb9525b574f4d2c49132d4f943139db1592fd27c31ed1e37d683ff` | `7c1f63a65cefc8b1f4acbb58ac0613e073a8bcf64657a1c70bdf93390b5052e9` |

두 빌드 모두 Node 검사 6/6을 통과했다. 자연 광석 선택과 시야 차폐, 강화별 효율, 8초 만료, 도구·지역 변경 시 초기화, 이전 월드 생성 버전, Worker의 healthz·PWA·OG 응답을 확인했다. Worker 본문에서 게임 HTML만 수정하며, HTML 안에서는 핵심 게임 스크립트 한 블록만 바뀐다.

PC 1280×800, Pixel 7 에뮬레이션 390×844 및 844×390에서 광맥 추적·저장 복원을 확인했다. 기존 디버그 도구로 채굴 테스트 위치를 잡고, PC 마우스와 모바일 터치 이벤트로 채굴 패드를 눌렀다. 석탄 1개 지급, HUD와 채굴 패드 비겹침, 새로고침 후 채굴 기록과 광석 보존, 추적 상태 초기화를 확인했다.

농장·요리 #13과 광맥 추적을 함께 적용한 빌드는 기존 브라우저 회귀 검사 Gate 5를 51/51로 통과했다. X46 첫 채굴과 보호 발판 18칸, 마을·유적·잔빛숲·벌목장 이동, v38 채굴·농사 세이브와 v41 벌목장 세이브의 복원을 확인했다.

## 저장 및 출시 판단

추적 상태는 메모리에만 둔다. 운영 저장 키·스키마·광석 보상·경험치·채굴 거리를 유지한다. Android 실기기 입력·멀티터치, BGM 재생, Cloudflare 시작 시간은 출시 전에 확인한다. 복구 기준은 현재 운영 v41 Worker다.
